本示例体现的 Gin / Go 特点

  • 单模块可运行：go run .，依赖由 go.mod 锁定。
  • RouterGroup：/api/box 子组挂载专用中间件。
  • ShouldBindJSON：struct tag 与 validator 对齐。
  • sync.Mutex：保护内存切片（对照 Node 单线程事件循环的写法差异）。
  • go:embed：呈现页打进二进制，拷贝单目录即可分发演示。
