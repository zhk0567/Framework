# SvelteKit 全栈示例

**SvelteKit 2 · Svelte 5 · Vite**。`src/routes/api/demo/+server.ts` 提供 **GET /api/demo**；首页在客户端 `fetch` 该地址。

## 快速开始（Windows PowerShell）

```powershell
Set-Location -LiteralPath 'f:\Study\Framework\Full-stack\SvelteKit'
npm install
npm run dev
```

默认 **http://127.0.0.1:3032/**（见 `vite.config.ts`）。
