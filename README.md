# Framework

用于**按架构分别搭建与对比**前后端技术栈的实验仓库（各子项目独立依赖与脚本）。

## 目录

| 路径 | 说明 |
|------|------|
| `Front-end/React` | React（Vite）示例与说明，见该目录 [README](Front-end/React/README.md) |
| `Front-end/Vue` | Vue（Vite）示例与说明，见该目录 [README](Front-end/Vue/README.md) |
| `Back-end` | 后端栈（按需补充） |

在子目录内安装依赖与启动开发服务器；资源与构建产物均落在对应子目录中。
