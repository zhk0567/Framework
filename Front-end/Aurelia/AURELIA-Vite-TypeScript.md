# Aurelia 2（Vite + TypeScript）

**@aurelia/vite-plugin** + `aurelia` 运行时；根组件 `my-app` 使用 HTML 模板绑定（`click.trigger`、`repeat.for`、`if.bind` 等）。

```powershell
Set-Location -LiteralPath 'f:\Study\Framework\Front-end\Aurelia'
npm install
npm run dev
```

默认开发端口在 `vite.config.ts` 中设为 **5177**（避免与其它 Vite 默认端口冲突）。
